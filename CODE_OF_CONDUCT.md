# Código de Conduta

Este projeto adota o [Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

## Resumo
- Seja respeitoso, acolhedor e inclusivo com todas as pessoas.
- Críticas devem ser construtivas e direcionadas a ideias, não a pessoas.
- Não são tolerados assédio, discriminação, linguagem ofensiva ou exposição de dados pessoais de terceiros.

## Aplicação
Comportamentos inaceitáveis podem ser relatados aos mantenedores da organização **Code Nexus Impact** pelos canais oficiais do GitHub. Todas as denúncias serão analisadas com sigilo, e os mantenedores poderão aplicar advertências, suspensões ou banimentos conforme o Contributor Covenant.
